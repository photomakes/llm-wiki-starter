# Работа со стартером

- Назначение, состав и быстрый старт описаны в [README.ru.md](README.ru.md).
- Для пробы продолжения задачи начни с [паспорта вымышленного проекта](projects/demo-project/README.md) и его [реестра](projects/demo-project/open-threads.md).
- При обновлении рабочих записей сохраняй статус и следующий шаг в реестре, решение в документе по теме, переносимое знание в [вике](wiki/index.md). У одного статуса или правила одно основное место.
- Открывай методику по задаче. Раскладка и проверка изменений описаны в [справочнике хранилищ](share/storage-architecture.md).
- Если применимые правила противоречат друг другу или правило мешает выполнить согласованную задачу, укажи конкретные формулировки, их источники и последствие для задачи. Проверь область действия и приоритет правил. Если этого достаточно, продолжи по применимому правилу и предложи уточнение, когда оно поможет избежать повторения. Если выбор остаётся за пользователем, предложи минимальную правку и запроси решение перед спорным действием. Остальную работу продолжай в пределах действующих правил.
- Для примеров используй вымышленные данные.
