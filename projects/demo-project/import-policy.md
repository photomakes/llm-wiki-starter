# Предварительный просмотр импорта

В этом вымышленном проекте принято показывать новые и уже существующие карточки до записи. Карточки считаются одинаковыми по имени и месту размещения. Совпадение помечается как «Уже в коллекции».

Коллекция меняется после явного подтверждения. Импорт добавляет только строки со статусом «Новая».
