# Открытые задачи

## Проверить предварительный просмотр импорта

- **Результат:** пользователь видит, какие строки будут добавлены и какие уже есть в коллекции.
- **Состояние:** поведение согласовано в [решении об импорте](import-policy.md). Проверка на файле с повтором ещё впереди.
- **Следующий шаг:** взять CSV с одной новой карточкой и одной существующей. Проверить, что предварительный просмотр показывает обе строки с разными статусами и оставляет коллекцию без изменений.
