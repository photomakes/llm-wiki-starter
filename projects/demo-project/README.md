# Карточки растений

Учебный пример для вымышленного приложения с домашней коллекцией растений. Документы описывают задачу импорта карточек из CSV и дают материал для проверки навигации в новом чате. В комплект входят только документы.

- [Открытые задачи](open-threads.md) показывают текущее состояние и следующий шаг.
- [Решение об импорте](import-policy.md) задаёт поведение предварительного просмотра.

## Разложите смешанную заметку

Допустим, после разговора осталась такая запись:

> Добавляем карточки после подтверждения. Ещё нужно проверить CSV с одной новой и одной существующей карточкой. Для пакетных операций полезно отделять предварительный просмотр от записи данных.

| Часть заметки | Куда её положить |
|---|---|
| Импорт записывает карточки после подтверждения | В [решение об импорте](import-policy.md), ярус B. Это поведение конкретного проекта. |
| Осталась проверка на CSV с повтором | В [реестр задач](open-threads.md), ярус B. Это следующий шаг. |
| Предварительный просмотр помогает перед пакетной записью | В [общую вику](../../wiki/index.md), ярус C, если вывод подтверждён и пригодится в других проектах. До проверки это гипотеза. |

## Проверьте продолжение в двух новых чатах

Возьмите отдельную копию стартера для упражнения или проведите проверку на своём проекте. В обоих чатах задайте один вопрос, без пересказа предыдущего ответа:

> Каково текущее состояние задачи импорта, какой следующий шаг и какое ограничение действует? Укажи документы, на которые опираешься.

1. **Первый чат.** Агент должен найти в реестре предстоящую проверку CSV с одной новой и одной существующей карточкой, а в решении об импорте — требование явного подтверждения перед записью.
2. **Между чатами.** Измените состояние и следующий шаг в реестре. Для упражнения можно отметить проверку CSV с повтором как выполненную и назначить следующей проверку отмены после предпросмотра. Политику импорта оставьте прежней. В своём проекте запишите фактическое изменение.
3. **Второй чат.** Повторите вопрос в той же рабочей папке. Проверка пройдена, если агент назовёт обновлённое состояние и новый шаг по реестру, а ограничение возьмёт из решения об импорте.
