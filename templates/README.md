# Бланки

- [Правила проекта](AGENTS.template.md) скопируйте в корневой `AGENTS.md`. Подставьте реальные адреса паспорта и реестра. Укажите только применимые ограничения и проверки.
- [Паспорт проекта](project-readme.template.md) скопируйте в `README.md` проекта или в `__wiki/README.md`.
- [Реестр задач](open-threads.template.md) скопируйте в `open-threads.md` рядом с паспортом. Укажите адреса обоих файлов в правилах проекта. Если храните реестр отдельно, обновите ссылку в паспорте.
- [Страницу вики](wiki-page.template.md) используйте для знания, которое пригодится повторно. Добавьте новую страницу в индекс.
